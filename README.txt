# LP STUDIO PWA

아이폰에서 앱처럼 사용할 수 있는 LP STUDIO 웹앱입니다.

## 가장 쉬운 설치 방법
1. 이 폴더의 파일을 HTTPS로 제공되는 웹 주소에 업로드합니다.
2. iPhone의 Safari로 그 주소를 엽니다.
3. 공유 버튼(□↑)을 누릅니다.
4. "홈 화면에 추가"를 누릅니다.
5. 홈 화면의 LP STUDIO 아이콘으로 실행합니다.

## GitHub Pages 사용
- GitHub에서 새 repository를 만듭니다.
- 이 폴더의 파일을 모두 업로드합니다.
- Settings → Pages → Deploy from branch → main / root를 선택합니다.
- 생성된 `https://...github.io/.../` 주소를 Safari에서 엽니다.

## 기능
- 앨범/트랙 관리
- 앨범 및 트랙 커버
- BPM / Key / Genre / 설명
- 가사
- Production Checklist
- 음원 업로드 및 재생
- 앨범/작업 정보 localStorage 저장
- 음원 IndexedDB 저장
- PWA 홈 화면 설치
